Projects

Main project · built solo

Doora

A platform where local service providers like plumbers, electricians and cooks register, and clients book them.

  • Five Spring Boot microservices, each with its own MySQL database.
  • Booking lifecycle (Booked, Completed, Cancelled, QuoteDeclined, Expired) with an OTP check on arrival and a two-round quote flow.
  • Kafka events published after each commit, keyed by booking id across 3 partitions; an Email service sends updates to both sides.
  • Jenkins CI/CD: Maven build, JUnit tests, Docker images and deploy to Azure, with request-id tracing across services.
  • Load-tested with k6, Prometheus and Grafana. Found bottlenecks in Caddy's memory limit and in bcrypt hashing under login bursts.
